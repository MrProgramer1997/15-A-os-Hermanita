Esta carpeta queda reservada por si prefieres usar fotografias locales.

Recomendacion:
- Formato WebP o AVIF.
- 1200 px en el lado largo es suficiente para movil.
- Evita subir fotos privadas si el repositorio sera publico.

La version actual tambien permite guardar URLs de fotos publicas en el campo `photos` de Supabase.
